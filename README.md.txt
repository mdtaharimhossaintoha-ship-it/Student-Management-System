# 🎓 Student Management System Using C

A simple and professional console-based Student Management System developed using the C programming language.

## 📌 Project Overview

This project helps manage student records efficiently. It provides basic operations such as adding, viewing, searching, updating, and deleting student information.

## 🚀 Features

- Admin Login System
- Add New Student
- Display All Students
- Search Student by ID
- Update Student Information
- Delete Student Records
- Department-wise Student Search
- Student Statistics
- Automatic Data Storage
- Input Validation

## 🛠️ Technologies Used

- C Programming Language
- Structures
- Arrays
- Functions
- File Handling
- String Handling

## ⚙️ How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Compile the C file using GCC.

```bash
gcc student_management.c -o student_management
```

4. Run the program.

Windows:

```bash
student_management.exe
```

Linux:

```bash
./student_management
```
